# Критичний огляд репозиторію UsdRateNbu

Дата огляду: 2026-10-22. Оглянуто стан гілки `master` на коміті `de2b30a` (останній коміт власника, 2023-05-31). Посилання «файл:рядок» нижче стосуються саме цього стану.

Примітка: у гілці цієї сесії (`claude/usd-rate-nbu-0001-r7v7bm`) окрім цього огляду є коміт `34808dd` зі змінами коду, зроблений раніше в цій же сесії ще до отримання завдання на огляд. Огляд його не враховує; власник може прийняти або відкинути той коміт незалежно від огляду.

## Що це

Невеликий консольний скрипт на Python, який запитує в користувача дату у форматі YYYYMMDD і друкує офіційний курс долара США до гривні на цю дату за даними відкритого API Національного банку України. Репозиторій складається з одного файлу коду на 25 рядків, README на одне речення, `.gitignore` та одного Windows-скрипта для створення віртуального середовища. Зовнішніх залежностей немає, використовується лише стандартна бібліотека. Історія — два коміти за один вечір у травні 2023 року, після чого активності не було. За суттю це особиста утиліта «на один випадок», а не бібліотека чи продукт.

## Що перевірено запуском

Код синтаксично коректний (розбір через `ast.parse` без помилок). Запуск оригінального скрипта з датою `20240115` у пісочниці завершився необробленим трейсбеком `urllib.error.URLError`, бо пісочниця не має доступу до `bank.gov.ua`; це підтверджує, що будь-яка мережева помилка валить скрипт без зрозумілого повідомлення. Перевірити реальну відповідь API НБУ з пісочниці неможливо. Тестів у `master` немає, тож запускати було нічого.
